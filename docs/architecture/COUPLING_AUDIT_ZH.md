# FocusPal 耦合审计（Legacy Baseline）

**文档语言：** 中文  
**对应英文：** [COUPLING_AUDIT_EN.md](./COUPLING_AUDIT_EN.md)  
**审计对象：** 本 Canonical Workspace 中的 Legacy Baseline（commit `b84ebe6` 及同源业务代码）  
**审计性质：** 记录耦合；不在此文档中重构  
**说明：** 本工作区即 FocusPal 开发位置（`origin` → FocusPal）；下列问题来自当前基线代码证据，用于指导 **In-place** 迁移。禁止继续用其它用户 ID 做探测。

---

## 1. 严重级别

| 级别 | 含义 |
|------|------|
| Critical | 权限、数据泄露风险、数据损坏、重复写入 |
| High | 核心流程中断、状态不同步、契约不一致 |
| Medium | 职责混合、重复逻辑、测试困难 |
| Low | 命名、文档、局部可读性 |

---

## 2. 耦合判定标准（强制）

**文件行数只能作为 Coupling Review Trigger，不能单独证明高耦合，也不能因超过约 300 行自动拆分。**

触发审查后须结合：

- 同一组件混合 UI、网络、状态、数据转换与业务规则
- 改一个功能需改多个无关模块
- 状态存在多个权威来源
- 组件直接依赖后端字段细节
- 多处重复定义 API 契约
- 业务逻辑无法单独测试
- 循环或反向依赖

每条审计记录须包含：

1. 文件体积（Trigger 参考）  
2. 职责数量  
3. 外部依赖  
4. 状态所有权  
5. 修改影响范围  
6. 可测试性  
7. 推荐边界  
8. 是否本轮处理（治理阶段均为否）

拆分依据：职责、状态所有权、变化原因。

## 3. Critical 发现

### C1 — Tasks 接口缺少可靠 JWT 门禁

| 字段 | 内容 |
|------|------|
| 严重级别 | Critical |
| 表述 | 诊断发现部分 Tasks 接口在未携带有效 JWT 时仍接受 `user_id` 请求，因此存在跨用户访问和修改风险。当前只确认接口缺少可靠认证门禁，未使用真实第三方用户数据验证实际泄露范围。 |
| 证据 | 旧前端以 query/body 传 `user_id`；诊断期对无 Token 请求的观察（不扩大探测） |
| 影响 | 授权模型不可信 |
| 触发场景 | 受保护任务读写 |
| 推荐边界 | Phase 1：后端验 Clerk JWT；所有权校验；禁止信任客户端 `user_id` |
| 本轮 | 不处理 |

### C2 — AI 确认任务可能双写

| 字段 | 内容 |
|------|------|
| 严重级别 | Critical |
| 证据 | 确认路径同时调用 `sync_tasks` 与 `tasks/batch` |
| 影响 | 重复任务、状态混乱 |
| 推荐边界 | Phase 4：确认后单次写入 |
| 本轮 | 不处理 |

### C3 — 创建成功不回写服务端 ID

| 字段 | 内容 |
|------|------|
| 严重级别 | Critical |
| 证据 | 创建处理忽略响应中的服务端 id，继续使用前端临时 id |
| 影响 | 后续更新/删除错位 |
| 推荐边界 | Phase 2：服务端 ID 为权威并回写 |
| 本轮 | 不处理 |

## 4. High 发现

### H1 — API Base URL 默认值不一致

| 字段 | 内容 |
|------|------|
| 证据 | 一处组件默认本地端口；其它默认远程后端 |
| 推荐边界 | Phase 0：统一 API Client 与环境变量 |
| 本轮 | 不处理 |

### H2 — 契约字段不一致

| 字段 | 内容 |
|------|------|
| 证据 | 时间戳、周报、画像、聊天包装等前端期待与 OpenAPI/实测形状不一致 |
| 推荐边界 | Phase 0–2：OpenAPI 真源 + 生成 TS Client + 契约测试 |
| 本轮 | 不处理 |

### H3 — 暂停等状态不持久化

| 字段 | 内容 |
|------|------|
| 证据 | 暂停路径仅改前端状态、无对应持久化调用 |
| 推荐边界 | Phase 3：Focus Session 与状态持久化 |
| 本轮 | 不处理 |

### H4 — Review 失败时默认图/分伪装成功

| 字段 | 内容 |
|------|------|
| 证据 | 接口失败或形状不匹配时使用默认图表与固定分数 |
| 推荐边界 | Phase 5：仅真实数据；显式错误/空状态 |
| 本轮 | 不处理 |
